# Morphix Insights

Morphix Insights is a personal analytics tool that Morphix uses for its own accounts: the **Quran Vibe**
YouTube channel and the **طمأنينة** Facebook Page.

It reads each account's statistics through the official YouTube and Facebook APIs, with read-only access,
and shows the owner which videos do better than usual, when to post, and where viewers stop watching. It
runs only on the owner's own computer and is not offered to anyone else.
